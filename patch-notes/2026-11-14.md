# 2026-11-14

## Fixed
- Pasting a new Spotify client ID/secret or Deezer ARL into Settings now replaces the old value. Previously, clicking into a filled-in field and pasting added the new value after the old one, so "connect" silently saved nothing and kept using the old credentials.
- Clicking "connect spotify" or "connect deezer" with an invalid value no longer crashes deeRip. It now tells you what's wrong (Spotify client ID and secret are 32 characters each, the Deezer ARL is 192) and saves nothing.
- After reconnecting Spotify, the title bar no longer gets stuck on "spotify: not connected" once you've approved the app in the browser.
- The "connect spotify" tooltip no longer claims it won't overwrite the current session. Connecting replaces it.
